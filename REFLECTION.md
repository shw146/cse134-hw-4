# What did I repeat by hand?
I had to manually input filepaths pretty often because of how different pages would require different directory traversal or didn't require their own filepath. A lot of the time I could copy and paste, but I had no choice but to go back and edit things after copy and pasting. It wasn't quite by hand, but copy and pasting the links for stylesheets was pretty frustrating, and I'd have to write a new link for each markup file (apart from the cheese families).

# What happened when I moved a file?
Depending on the file either a lot or very little happened. With image files it was pretty annoying to have to change filepaths and same goes for the guide files with changing the paths to the global css files. Thankfully, I did all of the file system setup ahead of time, so I didn't run into these issues much. I could see how moving one of the global files in styles might completely break everything though and I could imagine that it might become a problem later on if the styles folder starts to get overloaded and it's hard to find the global files.

# What would I want a tool to generate for me?
It would be really cool to have an automatic filepath selector or at least one that I could maybe click through options really quickly. That would speed things up significantly when I'm doing a bunch of file system traversal to link files. In the best case scenario, I'd probably want something that would create a link when I click on two different files in my file system: one for the reciever file and one for the applied file.
